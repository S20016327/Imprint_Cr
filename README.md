# Imprint_Cr

مستودع المشروع الأساسي لـ **Imprint_Cr** — مُهيّأ بهيكلية مرنة وقابلة للتوسّع لإضافة الملفات والأكواد والمستندات والأصول لاحقاً.

---

## هيكل المستودع (Repository Structure)

```text
Imprint_Cr/
├── src/            # الشيفرة البرمجية والملفات التنفيذية للمشروع
├── docs/           # التوثيق، الخطط، والملاحظات المعمارية
├── assets/         # الأصول الثابتة (الصور، الخطوط، الوسائط، التصاميم)
├── .editorconfig   # توحيد تنسيق المحررات البرمجية
├── .gitignore      # استثناء الملفات المؤقتة والحساسة من Git
├── CHANGELOG.md    # سجل التغييرات والإصدارات
└── README.md       # الدليل التعريفي الرئيسي للمستودع
```

---

## البدء السريع (Quick Start)

1. لإضافة ملفات برمجية، ضعها داخل مجلد `src/`.
2. لإضافة مستندات أو خطط عمل، استخدم مجلد `docs/`.
3. لحفظ التغييرات محلياً عبر Git:

```bash
git status
git add .
git commit -m "feat: add initial project files"
```
