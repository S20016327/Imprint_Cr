# إبداع — فيلم الهوية

استوديو معاينة تفاعلي لفيلم علامة **إبداع**، بتنسيق عمودي 9:16 ومبني على البصمة اللونية المرفقة. يحتوي على حركة Canvas بدقة 1080×1920، معاينة قابلة للتحكم، ثلاث لوحات ألوان، وتصدير فيديو WebM من المتصفح.

## التشغيل

يمكن فتح `index.html` مباشرة في متصفح حديث، أو تشغيل خادم ملفات محلي:

```bash
python3 -m http.server 4173
```

ثم افتح `http://localhost:4173`.

## التفاعل

- التشغيل / الإيقاف وإعادة المشاهدة، أو النقر على شريط الزمن للانتقال.
- تبديل لوحة البصمة بين الذهبي، الأخضر البحري، والحبر الليلي.
- تعديل سطري العبارة من رابط «تعديل النص».
- «تصدير الفيديو» يسجل المشهد كاملاً لمدة 12 ثانية وينزّل `imprint-creative-film.webm` بدقة 1080×1920 و30 إطاراً/ثانية. يتطلب التصدير متصفحاً حديثاً يدعم `MediaRecorder` وWebM.

## بنية الملفات

- `index.html` — واجهة الاستوديو.
- `src/styles.css` — التصميم المتجاوب.
- `src/app.js` — المشهد المتحرك والتحكم والتصدير.
- `assets/fingerprint-*.png` — علامات البصمة المرفقة بالألوان الثلاثة.
- `assets/imprint-poster-reference.png` — الملصق الأصلي للمرجع.

## النسخة الجاهزة للتحميل

النسخة النهائية موجودة في `deliverables/imprint-creative-film.mp4`، بترميز H.264، ودقة 1080×1920، ومعدل 24 إطاراً/ثانية، ومدتها 12 ثانية. الفيديو صامت.

لإعادة إنشاء ملف MP4 من المصدر، ثبّت `Pillow` و`imageio-ffmpeg` و`arabic-reshaper` و`python-bidi` ثم شغّل:

```bash
python3 scripts/render_video.py
```

## تسلسل الفيلم — 12 ثانية

1. **00:00–00:04 | بداية الأثر:** ظهور بصمة إبداع مع لمعة مسح ناعمة.
2. **00:04–00:08 | توقيع الهوية:** دخول العبارة على إيقاع بصري هادئ: «للإبداع بصمة .. ولكل بصمة أثر».
3. **00:08–00:12 | أثرٌ يبقى:** تثبيت التكوين والتوقيع الختامي.
